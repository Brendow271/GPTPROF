# GPTPROF

Агент для автоматической оптимизации кода на основе данных профилирования Intel VTune Profiler с использованием LLM (Codestral/Mistral).

## Описание проекта

Проект представляет собой систему для анализа производительности кода и автоматической генерации рекомендаций по оптимизации. Система интегрирует данные профилирования из Intel VTune Profiler с исходным кодом и использует языковые модели для анализа узких мест и предложения оптимизаций.

- ✅ Индексация исходного кода (C++ файлы)

## Основные компоненты

### 1. Парсинг данных профилирования
- Экспорт данных из `.vtune` файлов в CSV формат
- Фильтрация по модулям и исходным файлам
- Выделение топ-N функций по времени выполнения

### 2. Индексация исходного кода
- Автоматический поиск C++ файлов (.cpp, .h, .hpp)
- Извлечение функций из исходного кода
- Сохранение структурированных данных в базу данных

### 3. Интеграция с LLM
- Использование Codestral API для анализа кода
- Генерация рекомендаций по оптимизации
- Автоматический рефакторинг кода

## Установка и настройка

### Требования
- Python 3.11+
- Intel VTune Profiler (для экспорта данных)
- API ключ Mistral/Codestral

### Установка зависимостей

```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

### Настройка конфигурации

Создайте файл `config.ini` в корне проекта и укажите ваш API ключ:

```ini
[API_KEYS]
MISTRAL_API_KEY = ваш_api_ключ
```

**Важно:** Файл `config.ini` не включен в репозиторий по соображениям безопасности. Создайте его локально после клонирования проекта.

## Использование

### Основные инструменты

1. **export_vtune_to_csv** - Экспорт данных из VTune в CSV
2. **filter_and_save_top_functions** - Фильтрация топ-N функций
3. **save_path_files_to_db** - Сохранение путей к файлам в БД
4. **process_functions_and_save_to_db** - Обработка функций и сохранение в БД
5. **optimize_function_by_id** - Оптимизация функции по ID из БД

### Пример использования

Откройте `Demo.ipynb` или `sample.ipynb` для примеров работы с системой.

## База данных

Проект использует SQLite базу данных (например, `openmw.db`) для хранения:
- Путей к исходным файлам
- Структурированной информации о функциях
- Данных профилирования
- Связей между функциями и файлами

База данных создается автоматически при первом использовании инструментов индексации. Файлы `*.db` не включены в репозиторий.

## Данные профилирования

Проект работает с данными профилирования OpenMorrowind, экспортированными из Intel VTune Profiler. CSV файлы генерируются при работе с системой через инструмент `export_vtune_to_csv`. Примеры файлов:
- `r004hs.csv` - основные данные профилирования
- `filtered_*.csv` - отфильтрованные данные по модулям
- `prepared_*.csv` - подготовленные данные для анализа

**Примечание:** Все файлы `*.csv` не включены в репозиторий и должны быть сгенерированы локально из ваших `.vtune` файлов.
